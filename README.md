# Web2Table Company Website

The public-facing company website for Web2Table, built as a modular React + TypeScript application with Vite.

## Development

Requirements: Node.js 20+ and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Project structure

- `src/App.tsx` — page composition and reusable section components
- `src/styles/global.css` — global reset, typography, design tokens, and shared controls
- `src/styles/app.css` — responsive layout and section styling
- `index.html` — document metadata and application entry

## Deployment

The production build is generated in `dist/`. Hostinger deployment configuration will be added after the company website is reviewed and the hosting workflow is confirmed.
